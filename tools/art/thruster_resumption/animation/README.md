# Fixed-north fusion capture tooling

Read the [capture contract](../../../../docs/art/thruster-resumption-20261117/animation-capture/CAPTURE_CONTRACT.md). Latest authority requires actual advected smoke-like particle ejecta, whole-engine surface crackles and brightness following actual electrical draw. Older ring/tube field lines and an independent baked global brightness sine are superseded. This tooling imports the pinned validated GLB into a fresh derivative. It does not modify an owner's source, GLB, fixtures/shared FMPL/prototypes or run a physical gas simulation. New functional-detail body pins are required before final capture.

`make_profile.py` accepts the owner's passing `capture-source-geometry.json`, including the actual aperture surface, separate downstream field origin where required, source-specific underlay-only GLB, exact body exclusions and finite fore receiver polygons. It refuses mismatched hashes. The initial 32 native pixels/BU calibration stays explicitly provisional until real native fitting.

Example PowerShell (use a fresh `$capture` directory for every source/script revision):

```powershell
$blender = 'C:\Program Files\Blender Foundation\Blender 5.0\blender.exe'
$capture = 'build/thruster-resume-20261117/final-wide-capture'
python tools/art/thruster_resumption/animation/make_profile.py --glb <final.glb> --validation <passing-independent-validation.json> --geometry <capture-source-geometry.json> --prototype large-void-fusion-thruster --stage FINAL_CAPTURE_CANDIDATE --frames 64 --size 768 --samples 64 --out "$capture/profile-input.json"
python tools/art/thruster_resumption/animation/run_capture.py --blender $blender --profile "$capture/profile-input.json" --out "$capture/output" --frames all
python tools/art/thruster_resumption/animation/verify_capture.py "$capture/output"
```

Use `--frames 0,16,32,48,64` for a pilot sampling of the 64-cell timeline, and then `--frames all` to resume missing images. `run_capture.py` uses a fresh Blender process for static, energy and field lanes, preventing the observed Blender 5 mixed Cycles→Eevee context crash; it retains command/log/source-hash receipts. Profiles default to 64 Cycles samples and field-only Eevee. Final detailed bodies use 768-square source cells; pilots keep 512. Exact native 32 px/BU calibration is preserved by scale compensation; model proportions and anchors retain their source positions. A pilot can omit unavailable underlay/aperture inputs but explicitly records blocked components; it cannot become final acceptance. The native importer expects 64 final dynamic cells. Final capture waits for current functional-detail body pins.

The capture is hash-resumable, including the derivative master, canonical camera modules and each completed PNG. It refuses changed inputs/scripts/master/images. Non-production pilot outputs and failures stay in their original directories. The per-frame receipt proves a fixed actual camera, unchanged physical geometry/matrices, timeline position, shader strengths and output SHA. The exact first/wrap PNGs are rendered, not duplicated. Missing source components remain explicit blockers.

`verify_capture.py` requires the complete final-source package. It rechecks all 130 dynamic PNG hashes and real decoded wraps, all adjacent nonrecycled downstream motion/acceleration witnesses, lifecycle fading and actual surface-ray anchors. Its report binds the separate already-passed native electrical-control proof while leaving final detailed-body pixels and fit to the native art fixture. Sparse studies retain `verify_pilot.py` and their pilot status.

For the narrow owner handoff, `--geometry` accepts `aperture-measurement.json` and reads the separately passing adjacent `service-underlay-receipt.json`. If a later bounded installation well replaces that original underlay, `rebase_profile.py --previous <capture-receipt.json> --underlay <new.glb> --validation <new-passing-receipt.json> --samples 64 --out <new-profile.json>` pins the new assembly while retaining the previous camera. It starts a new derivative and genuinely rerenders its selected frames; it does not relabel old evidence. Original source bodies, completed atlases, receipts and matching tool snapshots remain preserved.

The clean lane uses 64 samples with a fixed seed, denoising only cold body and service-underlay RGB. Cycles energy/shadow stay raw; field-only Eevee records its separate 64-TAA/128-volume-sample settings. Actual rendered coverage and loop-wrap gates must still pass; no synthesized common alpha is allowed. A recorded −3-stop emission-pass exposure preserves useful eight-bit energy contrast without changing imported source materials.

`package.py` verifies decoded PNGs, zero-RGB cold light, exact cold-body/black-witness alpha, preserved working-energy physical coverage, nonstatic working pixels, black projected shadow, exact RGBA wrap and original-image/atlas-cell correspondence. It then applies one lossless common crop to every layer and compensates the native shift by the crop's exact center displacement. Original full-canvas PNGs and camera registration remain available. No global brightness sine is baked. Real cold-body/coverage-witness alpha remains exact; working energy may add actual arc alpha while preserving the physical coverage.

A field-only Eevee comparison can retain the same geometry/camera with its own real RGBA wrap/alpha proofs; Cycles remains the clean static/energy renderer. This is rendered analytic advection, not a physical fluid bake or background refraction. Preview GIFs are quantized source previews, not native timing evidence.
