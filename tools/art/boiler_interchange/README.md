# Boiler static interchange tools

See [commands, scope and actual verification](../../../docs/art/boiler-v08-glb/README.md). Build only into a fresh local directory. The builder freezes frame zero of the exact hash-guarded source, snapshots evaluated meshes before mutation, repairs numerical geometry/UV defects, and exports a native branch plus GLB. Independent tools inspect the actual artifact, compare source geometry, check mating planes/sockets and render proof. Never use this branch to replace the working animation or native sprite registration implicitly.
