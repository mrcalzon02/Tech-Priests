# Boiler cold/working visual integration — rejected rest-frame study

The current BoilerPictureSet places a complete 96-frame working animation in `structure`; the authored idle atlas is unused. The installed 2.1.24 API offers `structure`, `fire`, `fire_glow` and `patch`; `fire` is a conditional overlay, not a replacement structure. Its documented gate is burning cooldown greater than 1.

A scratch candidate replaced only cell zero of each direction with the corresponding existing idle sprite. All 95 remaining working cells per direction were retained, as were the accepted scale, shift, physical connections and timing. Native cold/working/stopped screenshots were captured. Smoke alone is ambiguous because the inherited engine also emits smoke, so a second diagnostic marked the rest cell green and all other working cells red. The markers are outside the body, at source-cell rectangle `(24,40)..(47,63)`, at all four direction row blocks.

All four newly cold boilers at tick 120 show red, not green. Thus native `structure` does not reliably select the first cell as an idle rest pose. Red is also visible after fixture fuel removal. The rest-cell candidate is **rejected**, with no production atlas or Lua replacement. The exact internal engine frame-selection algorithm is not claimed from these captures. The diagnostic markers were used only in the isolated scratch profile.

The full-alpha scan also rejects simply placing a complete working body over a complete idle body. Across the 384 working cells, 2,601 pixels have less alpha than their idle counterparts; the maximum reduction is 106/255. Source-over composition cannot reduce underlying alpha, so it cannot exactly recover those moving silhouettes. Do not call a double-body overlay faithful without resolving those edges.

The native fixture directly supplies water/fuel and removes the supply to obtain graphical states. It checks sprites and labels; it does not assert throughput, recipes, fuel economy, control logic or behavior/regression results. Native state JSON and original screenshots are retained. Tick 120 is initially cold, 420 supplied working, 780 after direct fuel removal; residual native smoke alone is not evidence of atlas state.

The next production pass must use the recovered editable model to derive a genuine static cold body and activity layers suited to native conditional rendering. Preserve the three original rattle rigs as source authority: if moving silhouette parts cannot fit native layering, resolve the construction/render contract explicitly rather than silently freezing or dropping their animation. Keep all four accepted pipe registrations, and inspect close-up native cold, working and stopped views before promotion. Wire-anchor support remains a separate gate.
