# Boiler V08 — four-direction native wire attachment

The inherited vanilla connector was full-sized and drawn across the pressure vessels. The corrected native connector case is mounted on the measured top of `Steam rear cage upright`, model-space `(0.6671270728, 0.9216609597, 0.8431828022)`. Its frame is stationary across source frames 0–97. No boiler mesh, material, animation or source sprite was altered.

The existing orthographic camera, source-yaw permutation and accepted per-direction sprite scale/shift project that single physical mount into all four native directions. A matching ground projection positions wire shadows. The native connector artwork is scaled with the model's screen registration and its case tinted brass; wire pins, red/green endpoints, LED offsets and shadows receive the same affine transform. The four native artwork variations and original filenames remain intact. Connectivity IDs, reach settings, owner positions, body graphics, fuel/fluid values and physical pipe definitions are preserved. The pre-existing generated graphics module is retained unchanged as a normalized-text prefix.

`baseline/` preserves the incorrect inherited views. `connected/` and `disconnected/` are actual Factorio 2.1.24 captures of the corrected generated module in the isolated graphics-review profile. All four views of each state were inspected. Cases rest on the cage junction, both wire colors meet their native pins, and the cases/pins disappear cleanly on disconnect. The fixture connects an empty native combinator to expose the graphics; it does not test circuit control, recipes, throughput, fuel, AI or behavior/regression outcomes. Physical pipe readbacks remain connected in all views.

`native-baseline-connector.json` and `native-corrected-connector.json` are data-stage readbacks. Every sprite keeps its original file, frame and dimensions; all pin, sprite, LED and shadow transforms are independently checked. The projection helper agrees with Blender's float-rounded camera to about 0.000044 native pixels. This is reported in native pixel units, not presented as binary camera identity.

The production job now stores the measured source object, 3D mount, source-model SHA-256, native scale and case tint. `boiler_circuit_attachment.py` derives positions from the current capture camera and sprite registration, then emits the inline Lua template. Future sprite scale/shift changes therefore carry the connector along. A changed native source hash is rejected before output creation until the mount is remeasured. The actual exporter packaging path and this negative source guard passed against the independently reopened source pilot; its receipt is explicitly a pilot, not a full new capture. No sprite rerender or Actions run was needed for the attachment correction.

Raw native-review hashes and canonical Git text hashes are recorded separately; only CRLF/LF normalization differs. Native image hashes bind the viewed evidence.

The boiler's source, cold/working graphics, pipe fit and wire attachment slices are now reviewed against the approved V07b-derived model. This does not close the overall model goal or prove every mod configuration loads: the unconditional optional Mechanicus sprite namespace remains a separate known startup integration gate. The review profile enables the already-installed dependency.

G5 remains separately open: this wire-rendering slice does not provide an independently reimported current-model GLB with PBR, bounds and socket inspection. Native `.blend` reopening and sprite/circuit acceptance are not substitutes for that interchange gate.
