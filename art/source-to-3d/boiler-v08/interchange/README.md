# Static cold-pose boiler interchange

`boiler-v08-cold-interchange.blend` is an editable evaluated cold-pose branch of `../production-source.blend`. `boiler-v08-cold.glb` is its actual independently reimported export with three fixed sockets. Both preserve the approved geometry except explicitly measured numerical-sliver removal; UV repairs and artifact hashes are documented in [G5 evidence](../../../../docs/art/boiler-v08-glb/README.md).

This branch contains no working animation and does not supersede the native animation source or installed directional sprites. Rebuild using `tools/art/boiler_interchange/build.py`, then run the independent audits and view the actual renders.
