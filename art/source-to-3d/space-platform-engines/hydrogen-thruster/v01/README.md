# Hydrogen thruster V01

Editable authored model, static interchange GLB, source-reference hashes, builder and 18 packed PBR maps. The generator preserves the existing sprite's main component groups and adds the required fixed fluid interfaces and supported platform mount. Current acceptance, native previews, exact import paths and complete local commands are in [graphics integration evidence](../../../../../docs/art/hydrogen-thruster-v01/README.md).

`source-manifest.json` records the builder-time candidate state; the linked final validation records subsequent actual-artifact/native review. The source's seven idle/seven working emission poses feed Factorio sprite output; the GLB is the static cold model, not an animated runtime export. `exported-passes/` retains the idle-emission source channel intentionally unused by the current runtime module.
