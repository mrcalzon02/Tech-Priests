# V07 recessed hatches and rubber tracks

The projecting outlet blocks are removed. The central pillar is wider and has six real recessed hatch openings cut into its front skin, with metal jambs, sills and lifted red hatch leaves. Each opening leads directly to a slightly descending open chute containing a separate charcoal rubber track with soft cross ribs. Open tapered hoppers are retained. Cannon meshes, aim, positions and pneumatic pipes are preserved. Cradle storage props are removed to expose the path; one intact loose pineapple prop is posed at each hatch.

Exterior fictional game asset only. The rubber tracks and hatch leaves are separate static parts for later animation; no reload animation is authored. Internal distribution remains concealed. Run build_hatch_tracks.py using Blender 5.0.1, then make_review.py with Pillow.
