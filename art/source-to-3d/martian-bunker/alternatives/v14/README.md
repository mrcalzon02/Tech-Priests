# V14 bolted mounting plate and inset girders

Details the existing circular rotary mounting plate with eight actual recessed bays in the exposed top annulus. Solid radial webs and the original outer rim remain; each bay contains an inset diagonal girder member below the original deck surface. Sixteen bolt/washer/seat sets follow the outer perimeter. Uses existing dark iron, steel and recess materials with small bevelled edges.

The original plate diameter, height and assembly position are retained. New mount parts are parented to TURRET_TRAVERSE, not the cannon elevation assembly. All other V13 source meshes, material assignments and world transforms are checked for preservation, including chamfered cabinets, sensors, cannons, inset armour, corrugated hoses and segmented conveyors. The bunker base is untouched.

Run build_mounting_plate.py in Blender 5.0.1, then make_review.py with Pillow. Native Blender, evaluated GLB and actual Blender whole views and mounting plate close-ups are packaged after GLB reimport validation. No firing/reload animation is added in this static detailing pass.
