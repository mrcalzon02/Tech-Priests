# V12 corrugated compression hoses

Rebuilds the six pneumatic air-feed tubes beneath the cannon castings with a continuous ribbed compression-bellows profile. Broad rounded ridges and recessed valleys follow the original tube centerlines, with smooth transitions into the unchanged end sockets. The tube surface remains one continuous mesh per mirrored pair rather than a stack of separate rings. The original committed dark iron material is retained with continuous cylindrical UVs.

Every other V11 source mesh, material assignment and transform is checked for preservation. Cannon position, aim, inset plates, hatches, segmented conveyors, hoppers and retained sensor cluster are unchanged. Source hose centerline endpoints are checked against the original mesh-ring centers. Native Blender and evaluated GLB are saved and export-reimport checked; actual whole, side and close-up renders are packaged. Run build_corrugated_hoses.py in Blender 5.0.1, then make_review.py with Pillow.
