# V08 continuous segmented rubber tracks

Replaces the smooth ribbon and contrasting cross rods with closed loops of evenly spaced rubber shoes. Each loop has an upper carrying strand, rounded end turn, lower return and hatch-end turn. All shoes, including bends and return, use one shared charcoal vulcanized rubber material. Shoe spacing is sampled by distance around the complete loop, including its seam. Soft bevels define the segments without switching material. Metal chute sidewalls remain separate from the rubber loop.

Cannons, hatch geometry, hoppers and pneumatic pipes are retained. Static model pass; no reload animation is authored. The visible end turn and underside return establish continuous track form. Run build_segmented_tracks.py in Blender 5.0.1, then make_review.py with Pillow.
