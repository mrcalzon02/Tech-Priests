# V09 sensors and antennas

Adds a compact armoured roof optical cluster with two recessed teal lenses and a protective brow, six small barrel instrument pods, two short aerials with brass sockets and insulated bases, a rear control sensor box with three amber status lamps, two chunky rear cable runs with brass clips, and a roof auxiliary sensor puck. Existing V08 meshes, material slots and world transforms are hashed and preserved before export. Conveyor paths, hatches, hoppers, cannon positions and pneumatic pipes are untouched.

Uses the existing committed oxide red, iron and steel materials, plus muted glass, brass and rubber detail materials. No intense glow or oversized whip antennas. All changes are exterior visual game asset detail. Run build_sensor_fit.py in Blender 5.0.1, then make_review.py with Pillow. Native model, GLB and actual Blender multi-view renders are packaged after validation.
