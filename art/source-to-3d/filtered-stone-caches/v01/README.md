# Ten filtered stone caches V01

User-directed rapid family: the shared stone wall, centered curved tablet,
supplied skull/cog and circuit seats are unchanged. Only the inner stock varies:
coal, copper ore, copper plates, copper cable coils, bored iron gear stacks,
iron ore, iron plates, iron rods, stone rubble and cross-cut wood logs.

`catalog.json` lists every entity and its packed editable Blender source/actual
GLB under the named subdirectory. Each includes recovered original sprites,
actual prototype/item/recipe/filter contract, construction contacts, source/export
inspection, fixed-north capture, matching icon, integration and native evidence.
Shared stock PBR maps live in `textures/` and are packed into each source.
The exact common wall/tablet/matrix/topology/UV audit is `shared-wall-audit.json`.
Source inspection retains front/rear/side/clay views; production uses only the
actual fixed north orientation, with a real shadow and dedicated 64px icon.

These are static stock-type identifiers. The fill does not animate or claim to
track inventory quantity. There is no invented machinery, power or fluid port.
All six-slot inventories, recipes, ordinary inserter access, circuits and existing
runtime filter behavior are preserved. This is not a new per-slot hard filter:
without a valid priest/station pair, wrong items remain safely; blocked reroutes
restore them. With a valid pair and space, the installed steward physically
deposits them into real storage without spilling or voiding them.

Native proof covers all ten caches: four ordinary inserter input/output sides,
capacity blocking/recovery, both circuit colors and reach, mining and saved-game
reload. Filter proof invokes the actual installed production steward in its own
mod context, with real cache/station/priest/sink entities and native inventories.
It checks no-pair retention, blocked restoration, exact rerouting, allowed-item
preservation, conservation, no ground spill and no unresolved custody. The private
remote bridge is appended only to the isolated test copy of control.lua; production
control and the actual filter/storage-authority modules remain unchanged. No
replacement filter, mock deposit, diagnostic command or player-facing control ships.

`native-evidence/review.json` is the shared proof; each variant also has its own
`native-evidence/review.json` and actual in-game PNG. Actual export front/rear/clay
boards and the native gallery were viewed. All technical/native gates pass;
individual owner visual approval is not inferred from the rapid-batch request.
The overall queue remains open. Basic and Advanced Space Cargo Inventories follow.
