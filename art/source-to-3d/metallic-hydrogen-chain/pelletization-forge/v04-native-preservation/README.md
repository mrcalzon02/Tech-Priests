The native eight-second driver consumes only a private non-pellet token; live stock remains in a registered inventory and keeps decaying. Disabled dispatch recipes configure the output inventory for its current phase/quality, then the exact current HP, quality, tags and native deadline are copied. Expired work leaves inert. Four sequential mixed-quality units per direction are processed without refresh, healing, duplication or jams. The default native orientation was initially discarded for an item-only machine; a true forward item-egress vector now retains all four directions, with zero gameplay fluid boxes.

The due-only instability scheduler uses real LuaItem references across logistics and calls native spoilage at its exact deadline, retaining damage ceilings/custom tags that native result replacement would otherwise discard. Damaged chest/belt/ground/inserter/character/work-unit histories and full forge results are identical after an actual save at tick 200 and reload. Formed output decays while blocked; sealing/unsealing preserves remaining lifetime and shell condition. Destroying a working forge releases its live original stock. The safe normal adapter and unchanged accepted crucible both pass regression runs.

72 clean native snapshots were inspected privately. Separate temporary per-cell counters prove all eight cells at one cell per second in each of the four directions. Source/GLB separately prove loop closure; the stopped single native craft does not prove a continuous native loop boundary. Counter pixels are excluded. Actual authored sound binding loads at .70 gain; owner audition is not inferred.
